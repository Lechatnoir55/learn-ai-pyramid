# 金字塔审计清单

**用法（强制两遍流程）**

```
Pass 1  按 modes/<mode>.md 起草，不要在起草时想规则
Pass 2  把草稿冻结，照本文件对应档位逐条判定
        有任意 no → 按「修补动作」重写该段 → 重新审计该条 → 全 yes 才输出
```

**审计输出格式（硬性）**——内部完成，不展示给用户：

```
R1 yes
R2 no → 原文「标题『检索部分』是名词短语」→ 改为「检索质量决定 RAG 的上限」
R3 yes
...
```

每条必须**引用被判定的原文**（用「」括起），格式固定为 `编号 + yes/no + （若 no）原文「…」→ 修补动作`。
禁止输出「整体不错」「结构基本清晰」这类散文评价。每一条必须是 `编号 + yes/no + （若 no）修补动作`。
**审计过程与草稿一律不打印给用户。** 只有最终通过的版本才输出。

## 熔断（防无限重写）

- 同一批次审计**最多重写 3 轮**。每轮：修 no 项 → 重审该条 → 仍 no 进入下一轮。
- 3 轮后仍有 no → **不再重写**，直接输出当前版本，并在末尾低调标注一行：
  `以下 N 项未通过内部校验：<编号列表>`
- 不许无限循环重写，也不许静默输出（漏标 = 违规）。
- 标注示例（低调、不渲染）：`> 注：以下 1 项未通过内部校验：R6。`

档位：`concise` → 简版 8 项｜`howto` `jargon` → 中版 12 项｜`detailed` `mindmap` → 全版 16 项

# 简版（concise，8 项）

| # | 判定问句 | 若 no 的修补动作 | 依据 |
|---|---|---|---|
| **R1** | ① 删掉正文只读第一行，读者能拿到结论吗？该句是含判断动词的**断言**吗？**比喻可作辅助，但结论句本身必须是判断，不能只有比喻**；不能是定义句、不能是背景铺陈。② 全文是否**只有一个**中心思想——「所以」行必须是**由结论推导得出**的推论或行动。**判据：「所以」行换了主语或换了主张对象 → 双结论，判 no；同一对象上的推论/行动 → 判 yes。**（例：「会取代传统工作流」→「所以尽快迁移」＝同一对象的推论，**通过**；「MCP 值得接入」→「所以改用 A2A」＝换了主张对象，**违规**） | 把结论句提到最前；改写成断言句；删掉纯比喻开场（只打比方不给判断）；删掉第二个独立结论 | p22/p26/p37/p302 |
| **R2** | 是否存在**显式的关键句层**——2–4 条**独立成行**（标 ①②③ 或换行分段），而不是用逗号串在一段散文里？每条是否含**主语＋谓语**？以下三类**均判 no**：名词短语（「生态支持」）、**无主动宾短语**（「装上 SDK」「配置工具列表」）、类别预告（「优势是…」）。 | 补显式关键句层（独立成行）；每条改写为含主谓的完整句 | p31/p52/p65 |
| **R3** | 把句中的数量词和数字删掉后，该句是否仍陈述一个**可争议的判断**？（防「有三大优势」式空壳） | 说出各项共同点所隐含的意义，重写概括句 | p141/p308 |
| **R5** | 关键句层能否用**同一个实质性单一名词**概括？实质性 = 原因／代价／步骤／条件／风险／差异…… **「优势」「特点」「要点」「方面」这类空类别词不算**（否则与 R3 冲突）。需要用「和／以及」才能概括吗？<br>⚠️ **不重复计数**：R2 已判 no（不是完整句）或 R3 已判 no（空壳概括）时，**R5 暂缓**，先修补那两条再重审。 | 拆组或提高抽象层次后重验；把空类别词换成实质名词 | p28/p302 |
| **R6** | ① 该组是否**同质**（全为步骤／全为理由／全为问题）？**异质 → 先按 R5 拆组，拆完再判顺序**。② 同质时能否归入时间／结构／程度之一？③ 并列理由或优势：**实际排列顺序**是否已按重要性递减——判据是**排出来的顺序**确实如此，不只是「说得出哪条重要」。是 → 程度顺序，通过。 | 先拆异质组；再显式标注顺序类型并重排；三问全否则该组解散重建 | p28-29/p114/p306 |
| **R7** | ① 任取两条，能否构造一个实例**同时落入**两者（重叠）？② 出现「其他」兜底了吗？③ **遗漏仅在上层是「范畴」时才检**。<br>**范畴的判据（明确）**：上层句含「N 大／N 类／N 个／分为／包括／以下几类」等**穷尽性标记** → 按范畴处理，启用遗漏检查；否则按**结论**处理，遗漏不可证伪，**该项不适用，判 yes**。 | 按结果重划；删「其他」；补遗漏分支（仅范畴型上层） | p121/p144/p308 |
| **R8** | 上层引发的是什么疑问（为什么／如何／你怎么知道／哪一个）？下层**所有**要点是否都属于该疑问词锁定的类型？<br>⚠️ **R2 判 no 时 R8 暂缓**——无主谓的标签无法归类为原因／步骤／证据，先修补 R2 再重审 R8。 | 按疑问词替换下层要点类型；删重复项 | p31-32/p44/p76 |
| **R4** | 下层能否**倒推**出上层句？**仅当下层 ≥半数要点与上层主题无关时判 no**（例：上层讲成本，下层 2/3 讲安装步骤）。<br>「论证力度不足」＝同主题但不够强，**不判 no**——那是 R3／R5 管的。 | 剔除孤儿要点，或改写上层概括句 | p26-28/p302 |

> **防误判提示（务必先读）**
> 1. **暂缓规则**：R2 判 no → **R8 暂缓**；R2 或 R3 判 no → **R5 暂缓**。先修补上游项，再重审下游项。
>    同一处缺陷不要被 R2／R3／R5 重复记三次。
> 2. **R7 的遗漏**只在**范畴型**上层启用（看有无「N大／分为／包括」穷尽性标记）。
> 3. **R6 先看同质**——异质组先拆，不要拿「顺序不对」去打一个根本不该在一起的组。
> 4. **R4 只抓主题错位**（≥半数要点跑题），不抓论证强弱。
> 5. 若 R4、R6、R7 同时对同一样本判 no，大概率是误判，回头复核。

# 提醒项（软约束，不计入判定，但能改就改）

- 关键句控制在 2–5 条（p19-20「奇妙的数字 7」；p116「最好不要超过 4 个或 5 个」）。原文措辞是「最好」，不硬卡。
- 每个论点行 ≤20 汉字、只含一组主谓（p240「论点超过 12 个单词，或者包含不止一个主语和谓语时，就应该简化」）。
- 每组标题同句型对仗（p236）——已计入 P1。
- 抽象段落配骨架图（p270）——已计入 P6，`detailed` 中建议执行。
