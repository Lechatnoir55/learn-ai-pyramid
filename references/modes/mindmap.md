# 思维导图版（mindmap）

## 你要解决的问题

把概念做成一张**单栏长图 HTML 白板**，浏览器打开即可扫读、截屏。

**关键约束**：本 skill 不用「自由挑 3–6 个模块」那种拼盘做法。
拼盘没有结论，看完记不住。白板必须是**强制三层金字塔**。

## 前序

1. 先读 `../pyramid-rules.md` 的 **R1–R11 和 P1–P6**（尤其是 P4）
2. 按 `../source-discipline.md` 取材（**只用官方网页，不抓社交**）

## 强制三层结构

```
L1  结论 hero        —— 恰好 1 条，全页最大字，含判断动词的断言
L2  关键句卡         —— 恰好 2–4 张，同一切分维度，每张标题是完整断言句
L3  证据卡           —— 每张 L2 下 ≤3 条，每条带一个来源链接
```

**禁止任何板块浮在结论之外。** 如果一个卡片不属于 L1 结论的支撑，删掉它。
没有来源支撑的卡片，删掉它。

### L1 结论 hero
- 一句话，含判断动词，字号全页最大（建议 40–48px）
- 禁止类比、禁止定义句、禁止「XX 是什么？」做标题

### L2 关键句卡
- 恰好 2–4 张（少于 2 说明没拆开，多于 4 记不住）
- **同一切分维度**：能一起叫「三个原因」/「两类代价」吗？混入不同类型就重拆（R5）
- 每张标题是**完整断言句**，不是类别名（P4）
  - ❌「成本分析」「工作原理」「优势」
  - ✅「检索质量决定上限」「成本几乎全在检索环节」
- 顺序必须可标类型（时间/结构/程度），打乱无损 = 无序（R6）

### L3 证据卡
- 每张 L2 下 ≤3 条
- 每条是具体事实：时间、数字、人名、原话、产品名、命令
- 每条带一个 `href` 来源链接，**链接必须来自实际抓到的页面**

## HTML 要求

- **单文件自包含**：嵌 `<style>`，无外部依赖、无 CDN、无 JS 必需
- **响应式**：窄屏（≤640px）时多栏网格塌成单栏
- 底部注明：基于 N 条来源 · 生成于 YYYY-MM-DD

### 输出与打开（跨平台，务必照做）

1. 用 Write 工具写到**临时目录**：
   - Windows → `%TEMP%`（通常是 `C:\Users\<用户名>\AppData\Local\Temp`）
   - macOS → `/tmp`
   - Linux → `/tmp`
   - 文件名：`learn-ai-pyramid-whiteboard-<slug>.html`
   - slug = 概念名去空格转小写；中文保留（「智能体」→ `智能体`）
2. 打开：
   - **Windows**：Bash 执行 `start "" "<完整路径>"`
   - **macOS**：`open "<完整路径>"`
   - **Linux**：`xdg-open "<完整路径>"`
   - 打开失败就只返回文件路径，让用户手动打开
3. 在聊天里回一句「白板已在浏览器打开：<路径>」+ 菜单（菜单由 SKILL.md 拼接）

> ⚠️ 不要写死 `/tmp/`——Windows 上没有这个路径会失败。

## 层级视觉编码（P2）

- 一种样式 = 一个层次，样式阶梯要与层级严格对应
- 层级 ≤3；某层只有 1 项就删掉该层
- 建议：L1 hero（40–48px）→ L2 卡标题（20–24px）→ L3 证据（14–15px）
- 用**缩进或左侧色条**表现层级，不要只靠字号

## 卡片标题禁令（P4）

每张卡片的标题必须直接就是该卡要证明的结论，用完整句或含动词的短语。
❌「各地区利润份额」 ✅「西部地区约占利润的一半」
